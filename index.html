Anticipated Questions From Evaluator ("Ma'am") & Answers:

Q1: How does the hand gesture recognition work mathematically?
A: The model extracts 21 normalized 3D coordinates (x, y, z) per hand. We calculate 3D Euclidean distances between the wrist landmark (0), MCP joints, and fingertips (4, 8, 12, 16, 20). If the distance of a fingertip to the wrist is greater than its PIP joint, it is classified as extended. A pinch is detected when the Euclidean distance between landmark 4 (Thumb tip) and 8 (Index tip) falls below 0.07.
Q2: How is the Air Drum sound generated without lag?
A: Instead of fetching heavy static MP3 files from a server (which causes network jitter and buffering lag), we synthesize audio in real-time on the client using the browser's AudioContext. For example, the kick drum is an oscillator dropping from 160 Hz to 35 Hz with an exponential gain curve, achieving zero-latency audio playback under 5ms.
Q3: How does the Sobel Edge Detection in the Vision Filter work?
A: We convolve the live video pixel buffer with two 3x3 directional derivative kernels: Gx (detecting vertical edges) and Gy (detecting horizontal edges). The gradient magnitude is computed as √(Gx² + Gy²). Pixels exceeding a contrast threshold are rendered as glowing neon edges, demonstrating spatial image enhancement from Module 3.
